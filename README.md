# root_18day V7.15

능률VOCA 어원편 360 ROOT · 1,410 표제어를 18DAY(하루 4블록)로 재배치한 단일 파일 학습 앱입니다.

## V7.15 변경 요약 (V7.14 기준)

### 1. DAY 종료 보고 메일 — 학습 중단 방지
V7.14까지는 관리자 메일 전송에 성공해야만 DAY가 완료되었고, 학교 방화벽·오프라인·CDN 차단 환경에서는
DAY 종료 화면에서 빠져나올 수 없었습니다. V7.15는 다음과 같이 동작합니다.

- 메일 전송은 여전히 **필수 기본 경로**입니다. 1차 실패 시에는 재전송만 안내합니다.
- **2회 연속 실패하거나 오프라인이 감지되면** 대체 경로 두 가지가 열립니다.
  - `메일 앱으로 보고서 보내기` — 기기 메일 앱으로 보고서 본문을 채워 엽니다.
  - `오프라인 저장 후 DAY 완료 · 연결되면 자동 재전송` — DAY를 완료 처리하고 보고서를 보류함에 넣습니다.
- 오프라인으로 완료한 DAY는 `보고 전송 필수 대기` 상태로 표시되며, 네트워크가 복구되면
  자동으로 재전송되고 성공 시 **정식 완료로 승격**됩니다(관리자 화면에서 `보고 전송 완료`로 바뀝니다).
- 관리자 화면은 메일 게이트가 열려 있어도 진입할 수 있습니다(전송 실패 진단·수동 재전송용).

### 2. 문항 데이터 정제
PDF 자동 추출 과정에서 괄호 안 원어가 유실되어 `((또는 ))` 처럼 뜻이 사라진 문항이 있었습니다.

- `quiz_meaning` 441건 정제, 그중 **뜻이 유실되었던 31건은 원서 근거로 복원**
- 대표 복원: dialogue → 대화, 문답, 회화 / corps → 군단, 단(團) / curriculum → 교육 과정 /
  thesis → 논문, 논제 / route → 길, 항로·노선 / sphere → 구(球)·구형, 영역·분야
- 잔존 결함 0건 (`tests/qa_test.js` 의 `quiz_meaning_clean` 항목으로 상시 검증)

### 3. 자가점검 항목 추가
`오프라인 대체 완료 경로`, `보류 보고서`, `안전 백업`, `복구 스냅샷`

## 유지되는 기능
- 저장 키 `18dayRootStateV7` 유지 → **기존 학생 진도 그대로 이어집니다**
- 현재 상태 / 안전백업 / 복구 스냅샷 3중 보존, 응답 단위 즉시 저장
- 누적 오답 영구 보관, D+1 · D+3 · D+6 · 집중관리 예약 복습
- 예약 복습 재오답 시 한글 인지 강화 화면

## 배포
1. ZIP 내부 파일 **전체**를 저장소 루트에 배치합니다.
2. **기존 학생 진도를 이어받으려면 기존과 동일한 도메인·경로에 배포해야 합니다.**
   (localStorage는 출처별로 분리되므로 주소가 바뀌면 진도가 보이지 않습니다.)
3. GitHub Pages: `index.html` + `.nojekyll` 만으로 동작합니다.
   이 경우 `/.netlify/functions/...` 경로는 없으므로 EmailJS 경로만 사용됩니다.
4. Netlify: 메일 함수를 쓰려면 환경변수 `RESEND_API_KEY`, `REPORT_FROM_EMAIL` 을 반드시 설정하세요.
   미설정 시 함수가 503을 반환하고 EmailJS 경로로 넘어갑니다.

## 운영 주의
- 진도는 기기·브라우저의 localStorage에 저장됩니다. 기기 변경·브라우저 초기화·시크릿 모드 전에는
  관리자 화면에서 `진도 내보내기(JSON)`를 받아 두십시오.
- 외부 CDN(EmailJS·Pretendard·Google Fonts)이 차단된 망에서도 학습은 정상 동작합니다.
  폰트는 시스템 폰트로 대체되고, 메일은 위의 대체 경로로 처리됩니다.
