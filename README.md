# 18day_root V7.4 Simple Loop

영어 어원 학습, 4지선다 진단, 오답 해설, 조건부 간격복습, 관리자 완료 메일을 하나의 연속 흐름으로 연결한 18DAY 학습 웹앱입니다.

## 단순화된 핵심 흐름

```text
4지선다
→ 정답: 바로 다음 단어
→ 오답: 어원 + 단어 구조 해설 한 화면
→ 확인하고 다음 단어

구간 종료
→ 핵심 오답 최대 4개 철자 1회
→ 다음 구간 자동 진행

DAY 종료
→ 관리자 완료 메일 필수 팝업
→ 전송 성공 후 DAY 완료
```

## V7.4 변경사항

- ROOT별 별도 시작 화면과 시작 버튼 제거
- 6문항 미니보상 화면 제거
- 정답 문항은 추가 단계 없이 자동 진행
- 일반 오답 직후 철자 입력 제거
- 오답 비교와 어원 해설을 한 화면으로 통합
- 오답 화면 버튼을 `확인하고 다음 단어` 하나로 제한
- 구간 종료 복습은 핵심 오답 최대 4개만 선정
- 구간 복습 철자는 단어당 1회만 입력
- 틀리면 정답을 보여주고 자동으로 다음 항목 이동
- 구간 완료 보상 화면 없이 다음 구간 자동 진행
- D+1·D+3 선택형 오답은 정답 확인 후 다음 일정으로 이동
- D+6·집중 케어 철자는 1회 입력 후 자동 진행
- 관리자 메일 필수 완료 게이트 유지

## 유지 기능

- 18DAY · 360 ROOT · 1,410 표제어
- DAY당 4개 내부 집중구간
- 숫자키 1~4, 숫자패드, 마우스, 터치
- 오답 영구 이력 DB
- D0 → D+1 → 조건부 D+3 → D+6
- 방향별 숙달, eventId, revision, 안전백업
- 실제 활성 학습시간 측정
- DAY 18 이후 기억 확인
- 관리자 메일 성공 후에만 DAY 완료
