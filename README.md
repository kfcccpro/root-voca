## DAY 종료 보고 정책

관리자 메일 전송 성공은 **DAY 완료의 필수 조건**입니다. 학생이 스스로 이를 우회할 수 없습니다.

```
1차 실패 → 재전송 안내만 (대체 경로 숨김)
2차 실패 또는 오프라인 감지 → 선생님용 기능 2개 노출
   ├ 메일 앱으로 보고서 보내기 (mailto)
   └ 🔒 관리자 승인 후 오프라인 완료  ← 관리자 PIN 인증 필수
온라인 복귀 → 자동 재전송 → 성공 시 정식 완료로 승격
```

- **오프라인 완료는 관리자 PIN(`2007`)을 입력해야만 실행됩니다.** 학생 단독 실행 불가.
- 승인된 DAY는 `offlineApprovedBy: admin-pin` 으로 기록되고, 관리자 화면에 **보고 전송 필수 대기** 로 표시됩니다.
- 전송에 성공하면 `mailConfirmedAt`이 기록되고 `forced` 표시가 해제됩니다.
- 메일 게이트 안의 `관리자 PIN으로 전송 상태 진단` 버튼으로 교사가 진단·재전송할 수 있습니다.

## V7.16 변경 사항

### 1. 관리자 PIN 인증 (신규)
- `ADMIN` 진입 시 4자리 PIN(`2007`) 인증을 요구합니다.
- 소스에는 평문 PIN 상수 대신 FNV-1a 검증 해시만 저장합니다.
- 인증은 세션 단위이며 관리자 화면을 나가면 즉시 해제됩니다.
- **메일 게이트가 열려 있어도 PIN만 통과하면 진입할 수 있습니다.**
  전송 실패 진단과 보류 보고서 재전송은 교사가 반드시 할 수 있어야 하기 때문입니다.

> ⚠ 4자리 숫자 해시는 브라우저에서 약 25ms 만에 전수 대입으로 복원됩니다.
> 소스 보기로 즉시 노출되는 것을 막는 억제책이며, 실질적 접근 통제가 아닙니다.
> 엄격한 통제가 필요하면 서버 인증이 필요합니다.

### 2. 오답 학습 흐름 조정
- 당일 오답: 실제 정답을 **붉은색으로 3초** 표시 후 자동으로 다음 문제. 인지 단계 없음.
- 예약 복습(D+1 · D+3 · D+6)에서 **다시 틀렸을 때만** 한글 뜻 인지 화면 실행.
- 인지 화면: 영단어 고정 + 한글 뜻 글자별 표시, **진행 막대 제거**, **4초 후 NEXT 활성화**.

### 3. 메일 함수 보안
- 수신 주소를 서버 환경변수로만 결정합니다. 요청 본문의 주소는 신뢰하지 않습니다.
  (이전에는 본문의 `email`을 그대로 사용해 공개 메일 릴레이로 악용될 수 있었습니다)
- root_18day와 2000_18DAY 두 앱의 payload를 모두 처리하는 통합 함수입니다.

## DAY 종료 보고 정책

관리자 메일 전송은 **필수**입니다. 다만 학습이 멈추지 않도록 단계적으로 동작합니다.

```
1차 실패 → 재전송 안내만 (대체 경로 숨김)
2차 실패 또는 오프라인 감지 → 대체 경로 2개 노출
   ├ 메일 앱으로 보고서 보내기 (mailto)
   └ 오프라인 저장 후 DAY 완료 · 연결되면 자동 재전송
온라인 복귀 → 자동 재전송 → 성공 시 정식 완료로 승격
```

- 오프라인으로 완료한 DAY는 관리자 화면에 **보고 전송 필수 대기** 로 구분 표시됩니다.
- 전송에 성공하면 `mailConfirmedAt`이 기록되고 `forced` 표시가 해제됩니다.
